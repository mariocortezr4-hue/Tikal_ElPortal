# Catálogo Maestro de Activos - Tikal Unity Project

Estructura optimizada y depurada para control de versiones por commits individuales.

## Categorías Incluidas:
- **01_VEGETACION**: Cobertura vegetal y jungla.
- **02_ROCAS_Y_TERRENO**: Formaciones calizas y kársticas.
- **03_ARQUITECTURA_MAYA**: Muros, esquinas, plataformas, arcos y columnas.
- **04_ARTE_MAYA**: Estela tallada, altar circular y banca de piedra.
- **06_PROPS**: Cerámica rota, vasijas de agua y antorchas ceremoniales.
- **05_ELEMENTOS_NATURALES**: Jaguar Monstruo (Jefe/Criatura).
